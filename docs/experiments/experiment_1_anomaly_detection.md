样本 240 行；人工注入异常 20 行，正常 220 行。已与固定种子生成器完整比对一致。

使用现有 `detect_anomalies`：IQR 单独运行时为相同四个指标传入空阈值字典，IQR 倍数使用现有默认值 1.5；组合方法采用两类规则的并集。任一指标触发即判为异常行。未按标签调整阈值。

混淆矩阵的行依次为实际正常、异常，列依次为预测正常、异常：

- 固定阈值：`[[220, 0], [0, 20]]`

数据是模拟网络数据，`anomaly_label` 是模拟生成过程中的人工注入标签。固定阈值 F1=1.0 来自当前模拟数据；模拟异常生成机制与固定阈值规则具有较强一致性，实验主要用于验证检测模块功能正确性和分析流程可复现性，不能推广到真实校园网络。IQR 可能将未人工注入的统计偏离点判为异常。指标分母为 0 时记为 0。
